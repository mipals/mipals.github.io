Backpropagation as a Linear Solve

In the previous post on backpropagation, we showed that backpropagation is a special case of the adjoint method. In this post we skip the adjoint description and instead derive the same result directly from the chain rule.

1. The forward relation

We denote the data by 𝑢0 and the parameters by 𝜃∈ℝ𝑝. The network has 𝑁 layers, each of which is a function Φ𝑖 that takes as input outputs from previous layers (𝑢𝑖−1,…,𝑢0) as well as the parameters (𝜃), and produces the next layer output 𝑢𝑖. The full forward pass, including all layer outputs, can be expressed as

[𝑢1𝑢2⋮𝑢𝑁]⏟𝑢(𝜃)=[Φ1(𝑢0,𝜃)Φ2(𝑢1,𝑢0,𝜃)⋮Φ𝑁(𝑢𝑁−1,…,𝑢0,𝜃)]⏟Φ(𝑢(𝜃),𝜃)∈ℝ𝑑,

(1)

where 𝑑=∑𝑖=1𝑁𝑛𝑖 and 𝑛𝑖 is the size of 𝑢𝑖.

We introduce the projection 𝑃∈ℝ𝑟×𝑑 that takes out relevant layer-outputs, i.e.11 Often 𝑃 just picks out the last layer, i.e. 𝑢𝑃=𝑢𝑁=𝑃𝑢(𝜃),𝑃=(0…0𝐼𝑟).

𝑢𝑃(𝜃)=𝑃𝑢(𝜃).

(2)

Using this the loss function can be written as

𝒥︀(𝜃)=ℓ(𝑢𝑃(𝜃))+𝜇ℛ︀(𝜃),

(3)

where ℓ is the data loss and ℛ︀ is a regularization term.

2. Differentiating the network

Applying the chain rule to (1), we have

d𝑢d𝜃=𝜕Φ𝜕𝑢d𝑢d𝜃+𝜕Φ𝜕𝜃,henced𝑢d𝜃=(𝐼−𝜕Φ𝜕𝑢⏟𝐿)−1𝜕Φ𝜕𝜃⏟𝑀⊤.

(4)

Applying the projection 𝑃, it further follows that

d𝑢𝑃d𝜃=𝑃𝐿−1𝑀⊤.

(5)

At this point it is worth looking at the structure of the matrices. As the 𝑖th layer depends only on previous outputs, the matrix 𝐿 is block lower-triangular with identity blocks on the diagonal22 The sparsity pattern of the strictly lower/upper part of a (block) triangular matrix is a directed acyclic graph (DAG), which is often how backpropagation is introduced.. The triangular structure makes it efficient to solve the linear system

𝐿⊤Λ=𝑃⊤,Λ∈ℝ𝑑×𝑟.

(6)

Using Λ it follows that

d𝑢𝑃d𝜃=Λ⊤𝑀⊤.

(7)

In practice, as seen in the next section, one rarely needs to form d𝑢𝑃d𝜃 as a full matrix; it suffices to define products with it.

3. A scalar loss

Applying the chain rule to (3), we have

∇𝜃𝒥︀=(d𝑢𝑃d𝜃)⊤∇𝑢𝑃ℓ+𝜇∇𝜃ℛ︀=𝑀𝐿−⊤𝑃⊤∇𝑢𝑃ℓ+𝜇∇𝜃ℛ︀.

(8)

Given that ∇𝑢𝑃ℓ is a vector of length 𝑟 we have that the product 𝑃⊤∇𝑢𝑃ℓ is a vector of length 𝑑. It is therefore of interest to first form 𝑃⊤∇𝑢𝑃ℓ and then solve 𝐿⊤𝜆=𝑃⊤∇𝑢𝑃ℓ, so that

∇𝜃𝒥︀=𝑀𝜆+𝜇∇𝜃ℛ︀,

(9)

which is equivalent to the final result of the adjoint method (see the previous post on backpropagation). Note that 𝜆 here is the negative of the adjoint variable of the previous post, which absorbs the sign of 𝜕𝑓𝜕𝜃=−𝑀⊤ there.
