1. Scalar derivatives

Dual numbers are a key part of forward-mode differentiation. However, I find the introduction of them unintuitive. Usually, as done in [1], they are introduced such that

𝑓(𝑥+𝜀)=𝑓(𝑥)+𝑓′(𝑥)𝜀,

(1)

where 𝜀2=0. This is not incorrect. However, I think it is more natural to think of dual numbers, at least in the context of automatic differentiation, as a number type that simply tracks both 𝑓(𝑥) and 𝑓′(𝑥) at the same time by introducing an 𝜀. This is sort of similar to how a complex number can be seen to track an 𝑎 and 𝑏 at the same time by introducing an 𝑖. However, for complex numbers the aim is to be able to solve 𝑥2=−1. For dual numbers the intent, as noted before, is to track 𝑓(𝑥) and 𝑓′(𝑥) at the same time. We therefore define how a function acts on a dual number by the composition rule

𝑓(𝑔(𝑥)+𝑔′(𝑥)𝜀)≔𝑓(𝑔(𝑥))+(𝑓(𝑔(𝑥)))′𝜀=𝑓(𝑔(𝑥))+𝑓′(𝑔(𝑥))𝑔′(𝑥)𝜀,

(2)

of which (1) is the special case 𝑔(𝑥)+𝑔′(𝑥)𝜀=𝑥+𝜀. In the same way we define multiplication and division of dual numbers by the product and quotient rules

(𝑓(𝑥)+𝑓′(𝑥)𝜀)(𝑔(𝑥)+𝑔′(𝑥)𝜀)≔𝑓(𝑥)𝑔(𝑥)+(𝑓(𝑥)𝑔(𝑥))′𝜀=𝑓(𝑥)𝑔(𝑥)+(𝑓′(𝑥)𝑔(𝑥)+𝑓(𝑥)𝑔′(𝑥))𝜀,𝑓(𝑥)+𝑓′(𝑥)𝜀𝑔(𝑥)+𝑔′(𝑥)𝜀≔𝑓(𝑥)𝑔(𝑥)+(𝑓(𝑥)𝑔(𝑥))′𝜀=𝑓(𝑥)𝑔(𝑥)+𝑓′(𝑥)𝑔(𝑥)−𝑓(𝑥)𝑔′(𝑥)𝑔(𝑥)2𝜀,

(3)

and addition and subtraction by the sum and difference rules

(𝑓(𝑥)+𝑓′(𝑥)𝜀)+(𝑔(𝑥)+𝑔′(𝑥)𝜀)≔(𝑓(𝑥)+𝑔(𝑥))+(𝑓(𝑥)+𝑔(𝑥))′𝜀=(𝑓(𝑥)+𝑔(𝑥))+(𝑓′(𝑥)+𝑔′(𝑥))𝜀,(𝑓(𝑥)+𝑓′(𝑥)𝜀)+(𝑐+0𝜀)≔(𝑓(𝑥)+𝑐)+(𝑓(𝑥)+𝑐)′𝜀=(𝑓(𝑥)+𝑐)+𝑓′(𝑥)𝜀,(𝑓(𝑥)+𝑓′(𝑥)𝜀)−(𝑔(𝑥)+𝑔′(𝑥)𝜀)≔(𝑓(𝑥)−𝑔(𝑥))+(𝑓(𝑥)−𝑔(𝑥))′𝜀=(𝑓(𝑥)−𝑔(𝑥))+(𝑓′(𝑥)−𝑔′(𝑥))𝜀.

(4)

Now an initial complaint would be: What if 𝑓′(𝑥) (or 𝑔′(𝑥)) is not known—which is usually the case when forward-mode differentiation is applied to a general function 𝑓? The answer is that we don’t need to know them as long as the derivatives of the basic operations that make up 𝑓 are known. That is, we can simply evaluate 𝑓(𝑥+𝜀), which by (2) should give us the derivative of 𝑓 at 𝑥 as the coefficient of 𝜀. In the code example below we define the following composition rules for the elementary functions sin and exp as

sin(𝑎+𝑏𝜀)=sin(𝑎)+𝑏cos(𝑎)𝜀,exp(𝑎+𝑏𝜀)=exp(𝑎)+𝑏exp(𝑎)𝜀.

(5)

Note that in general 𝑏 does not have to come from the derivative of 𝑎 with respect to some variable.

2. Jacobian-vector products

For a multivariate function 𝑓:ℝ𝑛→ℝ𝑚 the simplest extension keeps a single 𝜀 and seeds each input 𝑥𝑗 with a direction 𝑣𝑗. The dual numbers then track the function value and a directional derivative (a Jacobian-vector product) at the same time, i.e.,

𝑓(𝑥+𝜀𝑣)=𝑓(𝑥)+(𝐽𝑓(𝑥)𝑣)𝜀,

(7)

where 𝐽𝑓(𝑥) is the Jacobian. This definition follows directly by looking at the 𝑖th entry as

𝑓(𝑥+𝜀𝑣)𝑖=𝑓𝑖(𝑥+𝜀𝑣)=𝑓𝑖(𝑥)+(∑𝑗=1𝑛𝜕𝑓𝑖(𝑥)𝜕𝑥𝑗𝑣𝑗)𝜀.

(8)

A thing to note here is that the sum is computed automatically by the dual number arithmetic, and hence we never form the Jacobian. From a scaling perspective, this is a big win as the Jacobian is 𝑚×𝑛 in size, and hence can be very large.

The price is that one evaluation gives one product 𝐽𝑓(𝑥)𝑣. Its cost is a small multiple of the cost of evaluating 𝑓, but the full Jacobian requires 𝑛 evaluations, one for each unit vector 𝑣=𝑒𝑗. Forward mode is therefore well suited when 𝑛 is small compared to 𝑚. In the opposite case reverse mode (backpropagation) is preferred. It computes one vector-Jacobian product 𝑤⊤𝐽𝑓(𝑥) per evaluation, also at a small multiple of the cost of evaluating 𝑓, so the full Jacobian requires 𝑚 evaluations, one for each unit vector 𝑤=𝑒𝑖. The price is that the intermediate values of 𝑓 must be stored for the backward pass. The common case of a scalar loss of many parameters (𝑚=1) needs only a single evaluation; see Backpropagation as a Linear Solve.11 In the notation of that post, the Jacobian of a network is 𝑃𝐿−1𝑀⊤, where 𝐿 is block lower triangular. Forward mode multiplies 𝑣 from the right, 𝑃(𝐿−1(𝑀⊤𝑣)), so the solve with 𝐿 is a forward substitution that follows the layers in order, exactly as the dual numbers do. Reverse mode multiplies 𝑤⊤ from the left, ((𝑤⊤𝑃)𝐿−1)𝑀⊤, so the solve becomes the backward substitution 𝐿⊤𝜆=𝑃⊤𝑤.
