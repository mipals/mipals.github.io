In this note we look at how the sign function can be approximated by compositions of polynomials, as in the Polar Express algorithm [1]. This simple idea has a number of applications in modern machine learning and optimization, as it can be used to approximate matrix functions using only matrix-matrix products, which are very efficient to compute on modern hardware such as GPUs. Applied to the singular values of a matrix, the approximation of the sign function gives the polar factor 𝑈𝑉⊤. This is, e.g., the basis of the update of the Muon optimizer [2], which would otherwise require an SVD, an expensive computation that is not very GPU friendly. Muon is explained as steepest descent in the spectral norm in Which Way Is Down? It is furthermore possible to approximate the ReLU function in a similar way, which can be used to project matrices onto the cone of positive semidefinite matrices.

1. The Singular Value Transformation

The singular value transformation is defined for any odd function 𝑓, as

𝑓(𝑀)≔𝑈𝑓(Σ)𝑉⊤,𝑀=𝑈Σ𝑉⊤.

(1)

When 𝑀 is square and symmetric, the singular value transformation of an odd 𝑓 coincides with the matrix function 𝑓(𝑀)=𝑄𝑓(Λ)𝑄⊤, which applies 𝑓 to the eigenvalues. Writing 𝑀=𝑄Λ𝑄⊤=(𝑄sign(Λ))|Λ|𝑄⊤ shows that 𝑈=𝑄sign(Λ), Σ=|Λ| and 𝑉=𝑄, and since 𝑓 is odd,

𝑓(𝑀)=𝑄𝑓(Λ)𝑄⊤=𝑄sign(Λ)𝑓(|Λ|)𝑄⊤=𝑈𝑓(Σ)𝑉⊤,

(2)

where the sign function is defined as the odd function

sign(𝑥):={1,𝑥>0,0,𝑥=0,−1,𝑥<0,

(3)

2. Approximating the Polar Normalization

Polar normalization corresponds to the singular value transformation when 𝑓 itself is the sign function, i.e.

polar(𝑀)=𝑈diag(sign(𝜎1),…,sign(𝜎𝑘))𝑉⊤=𝑈𝑉⊤,

(4)

where the last equality takes 𝑈 and 𝑉 from the compact SVD, which keeps only the singular vectors of the nonzero singular values. Zero singular values stay zero, as sign(0)=0.

Computed directly, the polar factor requires an SVD, which is computationally expensive and not very GPU friendly (it is primarily memory bound rather than compute bound). The Polar Express algorithm instead approximates the matrix sign function using just matrix-matrix products [1]. The key idea is rather simple: Approximate the function 𝑓 using a composition of polynomials, e.g.,

𝑓(𝑥)≈𝑝𝑘(𝑝𝑘−1(…𝑝2(𝑝1(𝑥))…)).

(5)

Since the above is a composition of polynomials, it can be evaluated using just additions and multiplications.

3. The Polar Express Algorithm

The basic question that the Polar Express algorithm aims to solve is as follows: Given a set of 𝑇 polynomials {𝑝𝑖(𝑥)=𝑎1𝑖𝑥+𝑎3𝑖𝑥3+𝑎5𝑖𝑥5}𝑖=1𝑇, can we find an optimal set of coefficients that minimizes the maximum error over a given interval [ℓ,𝑢]? Define their composition as 𝑝=𝑝𝑇⚬𝑝𝑇−1⚬⋯⚬𝑝1. We then solve

(𝑝1⋆,…,𝑝𝑇⋆)=arg min𝑝1,…,𝑝𝑇max𝑀∈ℝ𝑚×𝑛𝜎(𝑀)⊂[ℓ,𝑢]‖polar(𝑀)−𝑝(𝑀)‖2subject to𝑝𝑡∈ℝ5odd[𝑥],𝑡=1,…,𝑇.

(7)

Here ℝ𝑑odd[𝑥] denotes the space of real odd polynomials of degree at most 𝑑. Since 𝑝 is odd, 𝑝(𝑀)=𝑈𝑝(Σ)𝑉⊤, so the error is max𝑖|1−𝑝(𝜎𝑖)|, and the problem is the scalar one of approximating 1 on [ℓ,𝑢], or by oddness the sign function on [−𝑢,−ℓ]∪[ℓ,𝑢].

In [1] they show that the above can be solved by a greedy approach, with a caveat that the error bound only holds if the smallest singular value is at least ℓ, which we do not know in advance. Smaller singular values still converge, but more slowly. A comment here is that the main focus in the paper is on bfloat16. Here the spacing between representable numbers at 1 is 2−7=0.0078125, so singular values much smaller than this are at the level of rounding errors. They therefore suggest setting ℓ=10−3, and 𝑢=1 after scaling 𝑀 by its Frobenius norm so that 𝜎1≤1. In addition, they provide a few modifications in order to make the method numerically robust. These additions are skipped here, but can be found in the original paper.

4. Projection onto the semidefinite cone

The positive semidefinite cone is the set of all real symmetric 𝑛×𝑛 positive semidefinite matrices. That is

𝕊+𝑛:={𝑋∈ℝ𝑛×𝑛|𝑋=𝑋⊤,𝑋⪰0}.

(8)

Semidefinite programming (SDP) problems are optimization problems for which matrix variables are constrained to be positive semidefinite, a special case of the conic programs in Conic Optimization. As such, algorithms that aim to solve SDPs need to ensure that the solution satisfies the positive semidefinite constraint. In interior point methods this is done by only taking steps for which the next iterate remains inside the cone, while first-order methods most often rely on projecting back onto the set after taking a step, i.e., for a symmetric 𝑋=𝑈Λ𝑈⊤,

Π𝕊+𝑛(𝑋)=arg min𝑌∈𝕊+𝑛‖𝑌−𝑋‖𝐹=𝑈diag(ReLU(𝜆1),…,ReLU(𝜆𝑛))𝑈⊤.

(9)

While the idea of projecting back onto the semidefinite cone using just matrix-matrix products is not new (a similar fixed-point approach was suggested in [4]), the main takeaway is that the ideas of Polar Express can be used to find a faster converging method [5]. An initial idea would be to directly find polynomials that approximate the ReLU function, i.e., solving

inf𝑓1,…,𝑓𝑇max𝑥∈[−1,1]|𝑓𝑇⚬𝑓𝑇−1⚬⋯⚬𝑓1(𝑥)−ReLU(𝑥)|subject to𝑓𝑡∈ℝ𝑑𝑡[𝑥],𝑡=1,…,𝑇,

(10)

where 𝑇 is the total number of polynomials in the composition, 𝑑𝑡 is the degree of the 𝑡’th polynomial, and the degrees are fixed in advance as part of a “matrix-matrix” multiplication budget. Unfortunately, directly solving the above is challenging, and instead a two-stage approach is proposed. The idea is to realize that we can write the ReLU function as

ReLU(𝑥)=12𝑥(1+sign(𝑥)).

(11)

The first step is to compute optimal coefficients for approximating the sign function using the Polar Express approach. The second step is then to refine the coefficients of the polynomials found in the first step by minimizing the error to the ReLU function on the entire interval [−1,1], i.e., minimizing the following loss function

𝐿(𝑓𝑇,…,𝑓1):=max𝑥∈[−1,1]|12𝑥(1+𝑓𝑇⚬𝑓𝑇−1⚬⋯⚬𝑓1(𝑥))−ReLU(𝑥)|.

(12)
