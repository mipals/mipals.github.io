1. Introduction

This note introduces some central ideas behind the implementation of efficient interior-point methods for solving conic programs. A large portion of the theory section is based on the papers for the conic solvers Clarabel11 You can play around with a few examples using a Wasm-compiled Clarabel here. [1] and CVXOPT [2]. What this note adds is some essential implementation details that were left out of the original two papers (e.g. iterative refinement, matrix equilibration, and handling of the structure of the scaling matrices).

2. Primal and dual problems

We will in this text consider optimization problems where the objective function is at most quadratic and the constraints are conic (including the zero cone in order to model equality constraints). The general form of such (primal) problems is the following

minimize12𝑥⊤𝑃𝑥+𝑞⊤𝑥subject to𝐴𝑥+𝑠=𝑏𝑠∈𝒦︀,

(1)

where 𝑥∈ℝ𝑛 is the decision variable, 𝑠∈ℝ𝑚 is the slack variable, and 𝑃=𝑃⊤⪰0∈ℝ𝑛×𝑛, 𝑞∈ℝ𝑛, 𝐴∈ℝ𝑚×𝑛, 𝑏∈ℝ𝑚. Furthermore, 𝒦︀ is a composite i.e. the Cartesian product of 𝐾 cones (𝒦︀=𝒦︀1×…×𝒦︀𝐾) with each of the cones 𝒦︀𝑘 of dimension 𝑙𝑘 being of the following types

  • The zero cone: 𝒵︀𝑙𝑘≔{0}𝑙𝑘 (used to model equality constraints).
  • The nonnegative cone: ℝ+𝑙𝑘≔{𝑠∈ℝ𝑙𝑘|𝑠≥0}.
  • The second-order cone: 𝒬︀𝑙𝑘≔{(𝑠1,𝑠2)∈ℝ×ℝ𝑙𝑘−1|‖𝑠2‖2≤𝑠1}.
  • The exponential cone: 𝒦︀exp≔{(𝑠1,𝑠2,𝑠3)∈ℝ3|𝑠2exp(𝑠1𝑠2)≤𝑠3,𝑠2>0}∪{(𝑥,0,𝑧)|𝑥≤0,𝑧≥0}.
  • The power cone: 𝒦︀pow≔{(𝑠1,𝑠2,𝑠3)∈ℝ3|𝑠1𝛼𝑠21−𝛼≥|𝑠3|,𝑠1,𝑠2≥0} with 𝛼∈(0,1).
  • The positive semidefinite cone: 𝒮︀𝑙𝑘≔{𝑠∈ℝ𝑙𝑘(𝑙𝑘+1)2|smat(𝑠)⪰0}.

where smat(𝑥) creates a symmetric matrix from the vector 𝑥. This can be done in a plethora of ways, but we will use the definition from Clarabel, which fills the lower triangle row by row

smat(𝑥)=[𝑥1𝑥2/2⋯𝑥𝑛(𝑛−1)/2+1/2𝑥2/2𝑥3⋯𝑥𝑛(𝑛−1)/2+2/2⋮⋮⋱⋮𝑥𝑛(𝑛−1)/2+1/2𝑥𝑛(𝑛−1)/2+2/2⋯𝑥𝑛(𝑛+1)/2].

(2)

where the scaling of 2 have been introduced on the off-diagonal elements in order to preserve the inner product, i.e. 𝑥⊤𝑦=tr(smat(𝑥)smat(𝑦)). Furthermore, we denote the inverse operation by svec(𝑋), i.e. an operation that creates a vector from a symmetric matrix 𝑋. The nonnegative, second-order, and positive semidefinite cones are examples of symmetric cones which are a special class of cones that have a lot of nice properties. The exponential and power cones are examples of nonsymmetric cones which do not have the same nice properties as symmetric cones, but are still very useful in practice. The zero cone is a special case that is used to model equality constraints.

2.1. The dual problem

The primal optimization problem of interest can equivalently be written as

Primal Problem:{minimize12𝑥⊤𝑃𝑥+𝑞⊤𝑥,subject to𝑠=𝑏−𝐴𝑥∈𝒦︀.

(3)

where the conic constraint 𝑏−𝐴𝑥∈𝒦︀ can be understood as a generalized inequality, i.e.

0⪯𝒦︀𝑠=𝑏−𝐴𝑥.

(4)

However, the standard form (similar to LPs) requires that the inequality is turned the other way. As such we negate the expression, resulting in

𝐴𝑥−𝑏⪯𝒦︀0.

(5)

We now write up the Lagrangian as

𝐿(𝑥,𝑧)=12𝑥⊤𝑃𝑥+𝑞⊤𝑥+𝑧⊤(𝐴𝑥−𝑏)

(6)

Since −(𝐴𝑥−𝑏)∈𝒦︀ we must have that 𝑧 is in the dual cone 𝒦︀∗ in order for the Lagrangian to be a lower bound for any feasible 𝑥. This comes directly from the definition of the dual cone, i.e.

𝒦︀∗={𝑧∈ℝ𝑚|𝑧⊤𝑠≥0,∀𝑠∈𝒦︀},

(7)

so that, in particular, 𝑧⊤(𝐴𝑥−𝑏)≤0 for every 𝑥 with 𝑏−𝐴𝑥∈𝒦︀.

Now since we want to find a stationary point we compute the gradient of the Lagrangian and set it to zero

∇𝑥𝐿(𝑥,𝑧)=𝑃𝑥+𝑞+𝐴⊤𝑧=0.

(8)

Now notice that the Lagrangian can be written as

𝑥⊤(12𝑃𝑥+𝑞+𝐴⊤𝑧)−𝑏⊤𝑧

(9)

The thing inside the parentheses, is almost equal to the zero constraint on the gradient. By performing the mathematician’s favorite magic trick of adding zero followed by rearranging the expressions we end up with

𝑥⊤(12𝑃𝑥+𝑞+𝐴⊤𝑧)+(12𝑥⊤𝑃𝑥−12𝑥⊤𝑃𝑥⏟=0)−𝑏⊤𝑧=𝑥⊤(𝑃𝑥+𝑞+𝐴⊤𝑧)⏟∇𝑥𝐿(𝑥,𝑧)=0−𝑏⊤𝑧−12𝑥⊤𝑃𝑥.

(10)

As such the dual formulation of the problem becomes

Dual Problem:{maximize−12𝑥⊤𝑃𝑥−𝑏⊤𝑧,subject to𝑃𝑥+𝑞+𝐴⊤𝑧=0,𝑧∈𝒦︀∗

(11)

2.2. Homogeneous embedding

The standard KKT conditions for the primal problem are

𝐴𝑥+𝑠=𝑏𝑃𝑥+𝐴⊤𝑧=−𝑞𝑠⊤𝑧=0(𝑠,𝑧)∈𝒦︀×𝒦︀∗.

(12)

However, we can take a different path in order to solve the same problem. First we define the duality gap 𝛾 as the difference between the primal and dual objectives

𝛾:=(12𝑥⊤𝑃𝑥+𝑞⊤𝑥)−(−12𝑥⊤𝑃𝑥−𝑏⊤𝑧)=𝑥⊤𝑃𝑥+𝑞⊤𝑥+𝑏⊤𝑧=𝑠⊤𝑧

(13)

where we used that 𝑞=−𝑃𝑥−𝐴⊤𝑧 (from the gradient constraint) and 𝑠=𝑏−𝐴𝑥 (from the definition of the equality constraints). Because (𝑠,𝑧)∈(𝒦︀,𝒦︀∗) the duality gap is always nonnegative for any feasible point, and is zero at the optimal point (𝑥∗,𝑠∗,𝑧∗) when strong duality holds. We can therefore come up with a different optimization problem by combining the constraints of the primal and dual problem and with an objective to minimize the duality gap

minimize𝑥,𝑠,𝑧𝑠⊤𝑧,subject to𝑃𝑥+𝐴⊤𝑧+𝑞=0,𝐴𝑥+𝑠−𝑏=0,𝑥⊤𝑃𝑥+𝑞⊤𝑥+𝑏⊤𝑧=0,(𝑠,𝑧)∈𝒦︀×𝒦︀∗.

(14)

An issue with the above is that the duality gap is explicitly set to zero in the third equality constraint. This condition can be relaxed after a change of variables 𝑥→𝑥𝜏,𝑧→𝑧𝜏, and 𝑠→𝑠𝜏 and instead solve

Homogeneous embedding:{minimize𝑥,𝑠,𝑧,𝜏,𝜅𝑠⊤𝑧+𝜏𝜅subject to𝑃𝑥+𝐴⊤𝑧+𝑞𝜏=0,𝐴𝑥+𝑠−𝑏𝜏=0,𝜏−1𝑥⊤𝑃𝑥+𝑞⊤𝑥+𝑏⊤𝑧+𝜅=0,(𝑠,𝑧,𝜏,𝜅)∈𝒦︀×𝒦︀∗×ℝ+×ℝ+.

(15)

In [1] they go on to show the existence of solutions and infeasibility detection. This will be skipped here.

3. Barrier functions

Barrier functions are functions that are defined only inside of the feasible region (i.e. when 𝑠=𝑏−𝐴𝑥∈𝒦︀) and tend towards infinity when we move towards the boundary of the feasible set. They are useful as they can be used to approximate the constrained problem by an unconstrained problem

{minimize12𝑥⊤𝑃𝑥+𝑞⊤𝑥subject to𝐴𝑥+𝑠=𝑏𝑠∈𝒦︀,≈minimize12𝑥⊤𝑃𝑥+𝑞⊤𝑥+𝜇𝑓(𝑏−𝐴𝑥).

(16)

As 𝜇→0 the solution to the unconstrained problem tends towards the solution of the constrained problem. A naive approach would simply be to pick 𝜇 to be a small value in order to get a good approximation of the original problem. However, this is not a good idea as the resulting optimization problem is very ill-conditioned and hard to solve. Instead, interior-point methods start with a large value of 𝜇 and then track the solution of the unconstrained problem as 𝜇 decreases until we are reasonably close to the optimal solution of the original problem. Methods that rely on this strategy of solving a series of simpler problems are known as homotopy methods. As an example we will now describe the properties of the logarithmic barrier functions for the three symmetric cones22 That is the nonnegative, second-order, and positive semidefinite cone., but later we will also discuss the barrier functions for the exponential and power cones.

4.1. Scaling matrices

We now introduce the idea of a scaling matrix 𝐻. The choice of scaling matrix 𝐻 depends on which way we linearize the central path. For symmetric cones the most common choice is the Nesterov-Todd scaling. For nonsymmetric cones the central path is defined by the set of points satisfying (32). For the zero cone we set 𝐻=0.

For symmetric cones the central path described with (34) is linearized. The Nesterov-Todd scaling exploits the self-scaled property of symmetric cones to compute a unique scaling point 𝑤∈𝒦︀ satisfying

The above is defined in terms of the conjugate barrier function 𝑓∗(𝑧). This is in contrast to [4], which defines it in terms of the standard barrier function.

The overall aim is to find the optimal solution to the homogeneous embedding. This amounts to solving the nonlinear system of equations 𝐺(𝑣)=0 with the additional constraint 𝜅𝜏=𝜇. 5.1. The affine and centering directions

At every interior-point iteration we solve the KKT system for two sets of right-hand sides each, corresponding to the so-called affine and centering directions. In short this means solving (45) twice, however since the system matrix stays the same and the right-hand side (−𝑞,𝑏) stays the same the computation requires only a single numerical factorization 77 As the sparsity pattern does not change the symbolic factorization can be reused and three solves.

The two sets of right-hand sides correspond to a predictor step and a corrector step. The steps are also known as the affine step and the centering step. In our case the affine step has the right-hand side of

𝑑𝑥=𝑟𝑥,𝑑𝑧=𝑟𝑧,𝑑𝜏=𝑟𝜏,𝑑𝑠=𝑠,𝑑𝜅=𝜅𝜏,

(47)

where (𝑟𝑥,𝑟𝑧,𝑟𝜏) are the three components of the residual 𝐺(𝑣) at the current iterate 𝑣, while the corrector step has the right-hand side of

𝑑𝑥=(1−𝜎)𝑟𝑥,𝑑𝑧=(1−𝜎)𝑟𝑧,𝑑𝜏=(1−𝜎)𝑟𝜏,𝑑𝜅=𝜅𝜏+Δ𝜅Δ𝜏−𝜎𝜇,𝑑𝑠={𝑊⊤(𝜆⋄(𝜆⚬𝜆−𝜎𝜇𝑒+𝜂))(symmetric)𝑠+𝜎𝜇∇𝑓∗(𝑧)+𝜂(nonsymmetric),

(48)

where ⋄ denotes the inverse operator of ⚬. Computation of a higher-order correction term 𝜂 is a heuristic technique that is known to accelerate the convergence of IPMs significantly. The choice of this term varies depending on the choice of the scaling matrix 𝐻 and whether a given constraint is symmetric or not. For symmetric cones we use the Mehrotra correction 𝜂=(𝑊−⊤Δ𝑠)⚬(𝑊Δ𝑧), while for nonsymmetric cones we compute 𝜂 using the 3rd-order correction from [4], i.e.

𝜂=−12∇3𝑓∗(𝑧)[Δ𝑧,∇2𝑓∗(𝑧)−1Δ𝑠].

(49)

We set 𝜎=(1−𝛼aff)3 where 𝛼aff is the step size of the affine step.

5.2. Solver initialization

An essential consideration is how to choose the initial point 𝑣0. The initialization strategies depend on whether the objective is linear or quadratic and whether the cones are symmetric or not. However, in all cases the initial scalar values are set as 𝜏0=𝜅0=1.

5.2.1. Symmetric cones

The initialization strategies below can be thought of as projections of the equality constraints onto cones in the direction of the idempotent 𝑒 for each symmetric cone.

Quadratic objective. If 𝑃≠0 the initialization happens by solving the following linear system

[𝑃𝐴⊤𝐴−𝐼𝐸][𝑥𝑧]=[−𝑞𝑏]

(50)

with 𝐼𝐸=𝐼−𝐸 with 𝐸 being a matrix with ones on the diagonal corresponding to zero cones (i.e. equality constraints) but otherwise zero. The above linear system corresponds to solving the following optimization problem

(51)

From this solution we project 𝑧 and 𝑠 back to the interior of the cone

𝑥0=𝑥,𝑠0={−𝑧,𝛼p<−𝜖−𝑧+(𝜖+𝛼p)𝑒,otherwise,𝑧0={𝑧,𝛼d<−𝜖𝑧+(𝜖+𝛼d)𝑒,otherwise.

(52)

where 𝛼p=inf{𝛼|−𝑧+𝛼𝑒∈𝒦︀} and 𝛼d=inf{𝛼|−𝑠+𝛼𝑒∈𝒦︀}.

[0𝐴⊤𝐴−𝐼𝐸][𝑥𝑡𝑠𝑧]=[0−𝑞𝑏0].

(53)

From this we set

𝑥0=𝑥,𝑠0={−𝑠,𝛼p<−𝜖−𝑠+(𝜖+𝛼p)𝑒,otherwise,𝑧0={𝑧,𝛼d<−𝜖𝑧+(𝜖+𝛼d)𝑒,otherwise,

(54)

where 𝛼p=inf{𝛼|−𝑠+𝛼𝑒∈𝒦︀} and 𝛼d=inf{𝛼|𝑧+𝛼𝑒∈𝒦︀}.

5.3. Termination criteria

All termination criteria are based on unscaled problem data and iterates, i.e. after the Ruiz scaling has been reverted.

5.3.1. Feasibility checks

For checks of primal and dual feasibility we introduce the normalized variables 𝑥̂=𝑥/𝜏, 𝑠̂=𝑠/𝜏, 𝑧̂=𝑧/𝜏 and define the primal and dual residual as follows

𝑟𝑝:=𝐴𝑥̂+𝑠̂−𝑏(primal residual)𝑟𝑑:=𝑃𝑥̂+𝐴⊤𝑧̂+𝑞(dual residual).

(58)

Likewise, we define the primal and dual objectives as

𝑔𝑝:=12𝑥̂⊤𝑃𝑥̂+𝑞⊤𝑥̂(primal objective)𝑔𝑑:=−12𝑥̂⊤𝑃𝑥̂−𝑏⊤𝑧̂(dual objective).

(59)

Using the above definitions we can declare convergence if all three of the following hold:

‖𝑟𝑝‖<𝜖𝑓⋅max{1,‖𝑏‖∞+‖𝑥̂‖+‖𝑠̂‖}(primal convergence)‖𝑟𝑑‖<𝜖𝑓⋅max{1,‖𝑞‖∞+‖𝑥̂‖+‖𝑧̂‖}(dual convergence)|𝑔𝑝−𝑔𝑑|<𝜖𝑓⋅max{1,min{|𝑔𝑝|,|𝑔𝑑|}}(gap convergence)

(60)

We specify a default value of 𝜖𝑓=10−8 as well as a weaker threshold of 𝜖𝑓=10−5 when testing for “near optimality” in cases of early termination (e.g. lack of progress, timeout, iterations limit, etc.).

5.3.2. Infeasibility checks

When testing for infeasibility we do not normalize iterates, but rather work directly with the unscaled variables since infeasibility corresponds to the case where 𝜏→0. We declare primal infeasibility if the following holds

‖𝐴⊤𝑧‖<−𝜖𝑖,𝑟⋅max{1,‖𝑥‖+‖𝑧‖}⋅(𝑏⊤𝑧)(primal infeasibility)𝑏⊤𝑧<−𝜖𝑖,𝑎(primal infeasibility).

(61)

Similarly, we define dual infeasibility if the following hold

6. Implementation details

6.1. Solving the KKT system

The main computational effort in the interior-point method is to solve the Karush-Kuhn-Tucker (KKT) system of the form

[𝑃𝐴⊤𝐴−𝐻]⏟𝐾[𝑥𝑧]⏟𝑦=[𝑏𝑥𝑏𝑧]⏟𝑏,

(63)

The scaling matrix, however, has the unfortunate property that it becomes ill-conditioned when the iterates are close to the boundary. As such one instead solves the regularized problem

[𝑃+𝜖𝐼𝐴⊤𝐴−(𝐻+𝜖𝐼)]⏟𝐾+𝐷[𝑥𝑧]⏟𝑦=[𝑏𝑥𝑏𝑧]⏟𝑏,

(64)

where 𝐷 denotes the added diagonal part. Note that while solving (64) is more numerically stable, it is not the system that we actually aim to solve i.e. (63). The regularization 𝜖 is computed as

𝜖=𝜖constant+𝜖proportion‖diag(𝐾)‖∞.

(65)

6.2. Regularized iterative refinement

As described in [5], the regularization term can be removed by solving a sequence of systems of the form

(𝐾+𝐷)Δ𝑥𝑚=𝑏−𝐾𝑥𝑚,𝑥𝑚+1=𝑥𝑚+Δ𝑥𝑚.

(66)

The sequence {𝑥𝑚} converges to the true solution of 𝐾𝑥=𝑏, provided that it exists. To show this first notice that we can rewrite (66) as

(𝐾+𝐷)𝑥𝑚+1−𝐷𝑥𝑚=𝑏.

(67)

Now assume that 𝑥0 is the solution to the equation 𝐾𝑥0=𝑏 (which is the equation we aim to solve). Now we perform the mathematician’s favorite trick of adding 0 (in this case 𝐷𝑥0−𝐷𝑥0), it follows that

(𝐾+𝐷)𝑥0−𝐷𝑥0=𝑏.

(68)

We now subtract (68) from (67)

(𝐾+𝐷)(𝑥𝑚+1−𝑥0)−𝐷(𝑥𝑚−𝑥0)=0.

(69)

Rewriting the above gives us

𝑥𝑚+1−𝑥0=(𝐾+𝐷)−1𝐷(𝑥𝑚−𝑥0).

(70)

The final step is to take norms on both sides resulting in

‖𝑥𝑚+1−𝑥0‖≤‖(𝐾+𝐷)−1𝐷‖‖𝑥𝑚−𝑥0‖.

(71)

Thus, if ‖(𝐾+𝐷)−1𝐷‖<1 we have that 𝑥𝑚→𝑥0 for 𝑚→∞ (more precisely, it suffices that the spectral radius of (𝐾+𝐷)−1𝐷 is less than one).

6.3. Matrix equilibration

The equilibration in Clarabel is a modified version of Ruiz scaling [6], [7], similar as to what is done in the OSQP package [5]. The equilibration is based on the scaling of the constant part of the KKT system (i.e. the part excluding the primal-dual scaling matrices) as shown below

𝑀=[𝑃𝐴⊤𝐴0].

(72)

The aim is to find a diagonal scaling matrix 𝑆 such that

𝑆𝑀𝑆=[𝐷00𝐸][𝑃𝐴⊤𝐴0][𝐷00𝐸]=[𝐷𝑃𝐷𝐷𝐴⊤𝐸𝐸𝐴𝐷0],

(73)

is better conditioned. The above can be seen as a transformation of input data to a conic optimization problem

minimize12𝑥̄⊤𝑃̄𝑥̄+𝑞̄⊤𝑥̄subject to𝐴̄𝑥̄+𝑠̄=𝑏̄𝑠̄∈𝒦︀,

(74)

where 𝑥̄=𝐷−1𝑥, 𝑠̄=𝐸𝑠, 𝑃̄=𝑐𝐷𝑃𝐷, 𝑞̄=𝑐𝐷𝑞, 𝐴̄=𝐸𝐴𝐷, 𝑏̄=𝐸𝑏, with 𝑐>0 a cost scaling and 𝐸 chosen such that 𝐸𝒦︀=𝒦︀.

The main idea of the equilibration procedure is to scale the rows (and columns) for the matrix 𝑀 so that they have equal ℓ𝑝-norm. An efficient approximate solution to this problem is the so-called Modified Ruiz scaling described in [5] based on the Ruiz scaling described in [6].

7. Sparse solvers

More often than not the main computational time in an interior-point method is solving (64). Luckily, the linear system is often sparse leading to fast factorization algorithms. As such it is important to use an efficient implementation of a direct sparse solver if one wants the interior-point solver to be computationally efficient. In Clarabel it is possible to utilize the following sparse solvers

  • (Rust/Julia) Quasi-Definite LDL (QDLDL) based on [8]. Single threaded.

7.1. Sparsity exploitation

7.1.1. Augmented sparsity

In numerical computations one often meets a matrix of the form sparse-plus-low-rank. The general form of this is the following

𝐻:=𝑆−∑𝑖=1𝑛𝑉𝑣𝑖𝑣𝑖⊤+∑𝑖=1𝑛𝑈𝑢𝑖𝑢𝑖⊤=𝑆−𝑉𝑉⊤+𝑈𝑈⊤,

(75)

where 𝑆 is sparse and 𝑉=[𝑣1…𝑣𝑛𝑉] and 𝑈=[𝑢1…𝑢𝑛𝑈] with 𝑛𝑈,𝑛𝑉≪𝑛. The problem with the above matrix is that forming the outer products (i.e. assembling the plus-low-rank part) will ruin the sparsity of 𝑆 and 𝐻 in turn will be a dense matrix. Given that our aim is to solve a system of the form 𝐻𝑥=𝑏 lets look at the structure of 𝐻𝑥 by performing the product

𝐻𝑥=𝑆𝑥−𝑉(𝑉⊤𝑥⏟−𝑡𝑉)+𝑈(𝑈⊤𝑥⏟𝑡𝑈)=𝑆𝑥+𝑉𝑡𝑉+𝑈𝑡𝑈.

(76)

The above together with the constraints 𝑉⊤𝑥+𝑡𝑉=0 and 𝑈⊤𝑥−𝑡𝑈=0 we can solve 𝐻𝑥=𝑏 by solving the following equivalent system

[𝑆𝑉𝑈𝑉⊤𝐼𝑛𝑉0𝑈⊤0−𝐼𝑛𝑈]⏟𝐻aug[𝑥𝑡𝑉𝑡𝑈]=[𝑏00].

(77)

Note that while 𝐻aug is sparse it is larger. An important property of the augmented system is that if 𝑆−𝑉𝑉⊤≻0 (and hence 𝑆≻0) then 𝐻aug is Quasi-Definite and therefore strongly factorizable, meaning that for every permutation 𝑃 one can find 𝐿 and 𝐷 so that 𝑃𝐻aug𝑃⊤=𝐿𝐷𝐿⊤ [9].

7.2. Second-order cones

7.2.1. The Clarabel approach

Clarabel uses the same approach as in ECOS [10]. In short, they utilize that the structure of 𝑊𝑘⊤𝑊𝑘 for a second-order cone is augmented-sparse, meaning that it can be split as follows

𝑊𝑘⊤𝑊𝑘=𝑆𝑘−𝑣𝑘𝑣𝑘⊤+𝑢𝑘𝑢𝑘⊤,

(78)

where 𝑆𝑘−𝑣𝑘𝑣𝑘⊤≻0. We can generalize the above for all second-order cones by defining

𝑆=blkdiag(𝑆1,𝑆2,…,𝑆𝑛),𝑉=blkdiag(𝑣1,𝑣2,…,𝑣𝑛),𝑈=blkdiag(𝑢1,𝑢2,…,𝑢𝑛),

(79)

meaning that

𝑊⊤𝑊=𝑆−𝑉𝑉⊤+𝑈𝑈⊤.

(80)

As such the KKT of the form

[𝑃𝐴⊤𝐴−𝑊⊤𝑊][𝑥𝑧]=[𝑏𝑥𝑏𝑧]

(81)

can equivalently be solved by solving

[𝑃𝐴⊤00𝐴−𝑆−𝑉−𝑈0−𝑉⊤−𝐼00−𝑈⊤0𝐼][𝑥𝑧𝑡𝑉𝑡𝑈]=[𝑏𝑥𝑏𝑧00],

(82)

The approach is simple as it leaves 𝐴 intact and does not scale 𝑧. However, one has to deal with computing 𝑉 and 𝑈, which is not unique. In fact Clarabel and ECOS apply different approaches when calculating 𝑉 and 𝑈. A detail here is that one wants to compute 𝑉 and 𝑈 in a way for which 𝑆−𝑉𝑉⊤≻0 so that the system remains quasi-definite (and therefore strongly factorizable).

7.2.2. The CVXOPT approach

Another approach is that of CVXOPT. Here the diagonal-plus-low-rank structure of the scaling matrix of a second-order cone (and its inverse) is used, i.e. that

𝑊𝑘=𝐷𝑘+𝑢𝑘𝑢𝑘⊤,𝑊𝑘−1=𝐸𝑘+𝑣𝑘𝑣𝑘⊤,

(83)

where the 𝐷𝑘 and 𝐸𝑘 are diagonal. We can again bunch all the scaling matrices together by defining

𝐷=blkdiag(𝐷1,𝐷2,…,𝐷𝑛),𝐸=blkdiag(𝐸1,𝐸2,…,𝐸𝑛),

(84)

so that

𝑊=𝐷+𝑈𝑈⊤,𝑊−1=𝐸+𝑉𝑉⊤.

(85)

Note that 𝑈 and 𝑉 are defined as before, but are different since the 𝑢𝑘 and 𝑣𝑘 come from (83) rather than (78). We now show how the rank-update and the known inverse can be used explicitly in order to preserve sparsity. The KKT system of interest using Nesterov-Todd scaling is the following

[𝑃𝐴⊤𝐴−𝑊⊤𝑊][𝑥𝑧]=[𝑏𝑥𝑏𝑧]

(86)

By scaling the 𝑧-variable and multiplying the last row with 𝑊−1 one finds that

[𝑃𝐴⊤(𝐸+𝑉𝑉⊤)(𝐸+𝑉𝑉⊤)𝐴−𝐼][𝑥𝑊𝑧]=[𝑏𝑥𝑊−1𝑏𝑧].

(87)

For simplicity, we now define 𝑆=𝐴⊤𝑉

[𝑃𝐴⊤𝐸+𝑆𝑉⊤𝐸𝐴+𝑉𝑆⊤−𝐼][𝑥𝑊𝑧]=[𝑏𝑥𝑊−1𝑏𝑧].

(88)

We can now introduce new variables 𝛼,𝛽∈ℝ𝑛𝑉 resulting in

[𝑃𝐴⊤𝐸𝑆0𝐸⊤𝐴−𝐼0𝑉𝑆⊤00−𝐼0𝑉⊤−𝐼0][𝑥𝑊𝑧𝛼𝛽]=[𝑏𝑥𝑊−1𝑏𝑧00].

(89)

Where we have used that 𝐸=𝐸⊤ to show why the system is also symmetric. Now the above preserves sparsity. For SOCs, 𝐸𝑘=−𝛾𝑘−1𝐽 for a scalar 𝛾𝑘>0 (in CVXOPT, 𝑊𝑘=𝛾𝑘(2𝑤𝑘𝑤𝑘⊤−𝐽) for a vector 𝑤𝑘), so 𝐸𝐸 is diagonal with blocks 𝛾𝑘−2𝐼. If the scaling is normalized so that 𝛾𝑘=1, then 𝐸𝐸=𝐼, and we can reduce the above as

[𝑃𝐴⊤𝑆0𝐴−𝐼0𝐸𝑉𝑆⊤00−𝐼0𝑉⊤𝐸⊤−𝐼0][𝑥𝐸𝑊𝑧𝛼𝛽]=[𝑏𝑥𝐸𝑊−1𝑏𝑧00].

(90)

By rotating the rotated second-order cone back to the second-order cone form we can exploit the sparsity similarly to the regular second-order cone. This rotation can be done by applying the following transformation

7.4. Power cones

The conjugate barrier for certain power cones has a Hessian that, similar to that of second-order cones, can be represented using augmented sparsity [11]. The intuition here is that e.g. the generalized power cone reduces to a second-order cone when 𝑑1=1. Given that the augmented sparsity is only available for the conjugate barrier the following is only relevant in the case of dual scaling.

The generalized power cone is parametrized by 𝛼∈ℝ++𝑑1 such that

∑𝑖∈[𝑑1]𝛼𝑖=1

(92)

and is defined as

𝒦︀gpow(𝛼,𝑑1,𝑑2)={(𝑢,𝑤)∈ℝ+𝑑1×ℝ𝑑2|∏𝑖=1,…,𝑑1𝑢𝑖𝛼𝑖≥‖𝑤‖}

(93)

with dual cone

𝒦︀gpow∗(𝛼,𝑑1,𝑑2)={(𝑢,𝑤)∈ℝ+𝑑1×ℝ𝑑2|∏𝑖=1,…,𝑑1(𝑢𝑖𝛼𝑖)𝛼𝑖≥‖𝑤‖}

(94)

The power mean cone is parametrized by 𝛼∈ℝ++𝑑1 such that

∑𝑖∈[𝑑1]𝛼𝑖=1

(95)

and is defined as

𝒦︀powm(𝛼,𝑑1)={(𝑢,𝑤)∈ℝ+𝑑1×ℝ|∏𝑖=1,…,𝑑1𝑢𝑖𝛼𝑖≥𝑤}

(96)

with dual cone

𝒦︀powm∗(𝛼,𝑑1)={(𝑢,𝑤)∈ℝ+𝑑1×ℝ−|∏𝑖=1,…,𝑑1(𝑢𝑖𝛼𝑖)𝛼𝑖≥−𝑤}

(97)

The relative entropy cone is defined as

𝒦︀rel(𝑑)=cl{(𝑢,𝑣,𝑤)∈ℝ×ℝ++𝑑×ℝ++𝑑|𝑢≥∑𝑖=1,…,𝑑𝑤𝑖ln(𝑤𝑖𝑣𝑖)}

(98)

with dual cone

𝒦︀rel∗(𝑑)=cl{(𝑢,𝑣,𝑤)∈ℝ++×ℝ++𝑑×ℝ𝑑|𝑤𝑖≥𝑢(ln(𝑢𝑣𝑖)−1)∀𝑖=1,…,𝑑}

(99)

7.5. Generalized power cones

As shown in [11] the Hessian of the conjugate barrier for the generalized power cones is augmented sparse with 𝑛𝑢=1 and 𝑛𝑣=2, i.e. that

𝐻∗(𝑧)=𝐷+𝑝𝑝⊤−𝑞𝑞⊤−𝑟𝑟⊤.

(100)

where 𝑧≔(𝑢,𝑤) and 𝐷−𝑞𝑞⊤−𝑟𝑟⊤≻0 with

𝐷=[⋱𝜏𝑖𝜙𝑢𝑖𝜁+1−𝛼𝑖𝑢𝑖2⋱2𝜁𝐼𝑑2],𝑝=[𝑝0𝜏𝜁𝑝1𝑤𝜁],𝑞=[𝑞0𝜏𝜁0],𝑟=[0𝑟1𝑤𝜁],

(101)

where

𝑝0=𝜙(𝜙+‖𝑤‖2)2,𝑝1=−22𝜙𝜙+‖𝑤‖2𝑞0=𝜙𝜁2,𝑟1=2𝜁𝜙+‖𝑤‖2

(102)

and 𝜙=∏𝑖∈[𝑑1](𝑢𝑖𝛼𝑖)2𝛼𝑖, 𝜏𝑖=2𝛼𝑖𝑢𝑖 and 𝜁=𝜙−‖𝑤‖2.

For the power mean cone it is shown in [11] that the Hessian of the conjugate barrier is augmented sparse with 𝑛𝑢=1 and 𝑛𝑣=2, i.e. that

7.8. Semidefinite cones

We start by introducing the vectorization of a symmetric matrix 𝑀 defined below

svec(𝑀):=[𝑀1,1,2𝑀2,1,𝑀2,2,2𝑀3,1,…,2𝑀𝑛,𝑛−2,2𝑀𝑛,𝑛−1,𝑀𝑛,𝑛]⊤.

(108)

Note that the scaling of 2 is in order to preserve inner-products i.e. that tr(𝐿⊤𝑀)=svec(𝐿)⊤svec(𝑀). We equivalently introduce the matrization of a vector (and denote it by smat) which unsurprisingly has the property 𝑀=smat(svec(𝑀)) as

smat(𝑚):=[𝑚1𝑚2/2…𝑚𝑛(𝑛−1)/2+1/2𝑚2/2𝑚3…𝑚𝑛(𝑛−1)/2+2/2⋮⋮⋱⋮𝑚𝑛(𝑛−1)/2+1/2𝑚𝑛(𝑛−1)/2+2/2…𝑚𝑛(𝑛+1)/2].

(109)

Note that the scaling ensures that we preserve inner-products i.e. that 𝑢⊤𝑣=tr(smat(𝑢)smat(𝑣)).

7.8.1. Computing dense 𝑊𝑘⊤𝑊𝑘

In CVXOPT the Nesterov-Todd scaling of a semidefinite cone is described by the product

𝑊𝑘svec(𝑉)=svec(𝑅𝑘⊤𝑉𝑅𝑘),

(110)

However, stating it like this gives no insights into the structure of 𝑊𝑘, which is needed when assembling the KKT system (to be precise 𝑊𝑘⊤𝑊𝑘 is needed for the KKT assembly). It turns out that the structure comes from the symmetric Kronecker product given by

(𝐺⊗𝑠𝐻)svec(𝑉)=12svec(𝐻𝑉𝐺⊤+𝐺𝑉𝐻⊤).

(111)

Using the above we can see that this means that the Nesterov-Todd scaling of the semidefinite cone is

(𝑅⊤⊗𝑠𝑅⊤)svec(𝑉)=svec(𝑅⊤𝑉𝑅),

(112)

from which it becomes clear that 𝑊𝑘=(𝑅𝑘⊤⊗𝑠𝑅𝑘⊤). We’re now almost ready to describe 𝑊𝑘⊤𝑊𝑘, but first we need to introduce the following property of the symmetric Kronecker product [12]

(𝐴⊗𝑠𝐵)(𝐶⊗𝑠𝐷)=12(𝐴𝐶⊗𝑠𝐵𝐷+𝐴𝐷⊗𝑠𝐵𝐶).

(113)

Using the above it follows that

𝑊𝑘⊤𝑊𝑘=(𝑅𝑘⊗𝑠𝑅𝑘)(𝑅𝑘⊤⊗𝑠𝑅𝑘⊤)=𝑅𝑘𝑅𝑘⊤⊗𝑠𝑅𝑘𝑅𝑘⊤

(114)

Now how do we write the symmetric Kronecker product as an explicit matrix? First we need to introduce a mapping 𝑄 that works as follows

𝑄vec(𝑆)=svec(𝑆),𝑄⊤svec(𝑆)=vec(𝑆)

(115)

Using 𝑄 it is now possible to describe the symmetric Kronecker product as

𝐺⊗𝑠𝐻=12𝑄(𝐺⊗𝐻+𝐻⊗𝐺)𝑄⊤

(116)

This definition intuitively makes sense. The 𝑄⊤ on the right is applied first and lifts a svec to vec i.e. from a symmetric vector to a regular vector. We then apply the sum of regular Kronecker products (the sum makes it map symmetric matrices to symmetric matrices) and then pull the product down back to svec using 𝑄. Note that in general 𝐺⊗𝑠𝐻 is not symmetric. Instead, it represents a single half of an otherwise symmetric product. In the case where 𝐻=𝐺, as is the case of NT-scaling, the product is symmetric and in fact

𝑊𝑘⊤𝑊𝑘=𝑅𝑘𝑅𝑘⊤⊗𝑠𝑅𝑘𝑅𝑘⊤=𝑄(𝑅𝑘𝑅𝑘⊤⊗𝑅𝑘𝑅𝑘⊤)𝑄⊤

(117)
