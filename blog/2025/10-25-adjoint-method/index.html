Backpropagation is often introduced as something developed within the field of machine learning. However, the reality is that backpropagation is just a special case of the adjoint method where the inversion of the partial derivative 𝜕𝑓𝜕𝑢 can be done efficiently due to its lower-triangular structure. This note is in two parts. In the first part we review the adjoint method while in the second part we describe how backpropagation is a special case of the adjoint method with a structure that results in scalable computational algorithms.

A key insight is that while the adjoint method is seemingly limited to equality constrained problems, it turns out that all computer programs are trivially equality constrained problems with equalities coming from each assignment11 All lines of code are essentially “variable=something” which can be written as “variable−something=0”. In this sense, as shown in a later section, optimizing a neural network is actually an equality constrained optimization problem with constraints coming from each layer of the network. This is opposed to how optimizing a neural network is usually presented as an unconstrained optimization problem.

1. The Adjoint Method

In many engineering applications we are interested in solving equality constrained optimization problems where the optimization variable (𝜃) implicitly defines another variable (𝑢) that then appears in the objective function22 A famous example of this is Topology Optimization. Written out this means solving optimization problems of the following form

min𝜃∈ℝ𝑛𝜃𝐿(𝑢,𝜃),(some objective function)subject to 𝑓(𝑢,𝜃)=0,(some equality constraint)𝑢∈ℝ𝑛𝑢.

(1)

Most methods for solving equality constrained optimization problems require the computation of the gradient of the objective function with respect to the optimization variable 𝜃. This is where the problem comes in: Naively computing the gradient requires the computation of the sensitivities of the implicitly defined variable 𝑢 with respect to the optimization variable 𝜃 (i.e.d𝑢d𝜃∈ℝ𝑛𝑢×𝑛𝜃). This results in a computational bottleneck as forming the sensitivities scales as 𝒪︀(𝑛𝑢𝑛𝜃), meaning that adding a new parameter adds 𝑛𝑢 additional sensitivities (and similarly adding one more variable would add 𝑛𝜃 additional sensitivities).

To resolve this computational bottleneck the adjoint method was introduced. The first step in the derivation of the adjoint method is to introduce the Lagrangian of the objective function, i.e.

ℒ︀(𝑢,𝜃,𝜆)=𝐿(𝑢,𝜃)+𝜆⊤𝑓(𝑢,𝜃).

(2)

It is easy to see that whenever 𝑢 satisfies the equality constraint 𝑓(𝑢,𝜃)=0, then the Lagrangian is equal to the original objective function. The reason why the introduction of the additional term in the Lagrangian is useful is that 𝜆 can be set to be anything. In particular, we aim to set it in a way so that we can avoid computing the otherwise computationally expensive sensitivities d𝑢d𝜃. We start by computing the total derivative of the Lagrangian with respect to 𝜃 33 The total derivative is the transpose of the gradient i.e. (d𝐿d𝜃)⊤=∇𝜃𝐿. That is multiplying the change in 𝜃 with the total derivative (rather than the transpose of the gradient) gives the change in the function 𝐿.

dℒ︀d𝜃=𝜕𝐿𝜕𝜃+𝜕𝐿𝜕𝑢d𝑢d𝜃+𝜆⊤(𝜕𝑓𝜕𝜃+𝜕𝑓𝜕𝑢d𝑢d𝜃).

(3)

Now we collect the terms that depend on the undesired d𝑢d𝜃, resulting in

dℒ︀d𝜃=𝜕𝐿𝜕𝜃+𝜆⊤𝜕𝑓𝜕𝜃+(𝜕𝐿𝜕𝑢+𝜆⊤𝜕𝑓𝜕𝑢)d𝑢d𝜃.

(4)

As we can choose 𝜆 freely a natural idea is to set it in a way such that the term in front of the undesired term vanishes. This means that we can choose 𝜆 as the solution to the equation

𝜕𝐿𝜕𝑢+𝜆⊤𝜕𝑓𝜕𝑢=0⇒𝜆⊤=−𝜕𝐿𝜕𝑢(𝜕𝑓𝜕𝑢)−1.

(5)

Inserting 𝜆⊤ back into the equation we find that the gradient of the Lagrangian with respect to 𝜃 is given by

dℒ︀d𝜃=𝜕𝐿𝜕𝜃−𝜕𝐿𝜕𝑢(𝜕𝑓𝜕𝑢)−1⏟𝜆⊤𝜕𝑓𝜕𝜃.

(6)

To conclude: The adjoint method is a simple way to avoid the computational bottleneck of computing the sensitivities d𝑢d𝜃 by cleverly computing the so-called adjoint variable 𝜆 in a way that eliminates the need to compute the problematic sensitivities.

2. Backpropagation and the Adjoint Method

Section 5.5 of [2] includes an example of how the adjoint method and backpropagation of neural networks are similar. In neural networks we are often interested in minimizing a loss function of the form

𝐿(𝜃;𝑢0)=‖Φ𝑁(𝜃;𝑢0)−𝑦‖22+𝜇ℛ︀(𝜃),

(13)

with 𝜃∈ℝ𝑘,𝑢0∈ℝ𝑚,𝑦∈ℝ𝑛 and the notation “;𝑢0” is used in order to highlight that 𝑢0 is a constant input (i.e. most often the “data”) and ℛ︀(𝜃) is some regularization function (e.g. ℛ︀(𝜃)=‖𝜃‖22). Furthermore Φ𝑁(𝜃;𝑢0):ℝ𝑘→ℝ𝑛 is a neural network with 𝑁 layers that given a set of constant inputs 𝑢0 maps the parameters 𝜃 to an output. Now, the above objective function does not include any equality constraints. However, one should realize that an 𝑁-layer neural network is nothing more than a composition of 𝑁 functions

Φ𝑁(𝜃;𝑢0)=Φ𝑁(Φ𝑁−1(⋯(Φ1(𝜃;𝑢0)⋯,𝜃;𝑢0),𝜃;𝑢0).

(14)

Now using the notation that 𝑢𝑖 is the output of the 𝑖th layer of the network we can write the propagation through the network as a large nonlinear system of equations that have to be satisfied

𝑓(𝑢,𝜃)=𝑢−Φ(𝑢,𝜃)=[𝑢1𝑢2⋮𝑢𝑁]⏟𝑢−[Φ1(𝜃;𝑢0)Φ2(𝑢1,𝜃;𝑢0)⋮Φ𝑁(𝑢1,…,𝑢𝑁−1,𝜃;𝑢0)]⏟Φ(𝑢,𝜃)=[00⋮0].

(15)

Using this notation (and removing the explicit dependence on 𝑢0) we see that optimizing a neural network is really nothing more than solving the following equality constrained optimization problem

min𝜃𝐿(𝑢,𝜃)=‖𝑢𝑁−𝑦‖22+𝜇ℛ︀(𝜃),subject to 𝑓(𝑢,𝜃)=0.

(16)

We can now use the adjoint method to compute the gradient of 𝐿 with respect to 𝜃. As a reminder this means that

d𝐿d𝜃=𝜕𝐿𝜕𝜃−𝜕𝐿𝜕𝑢(𝜕𝑓𝜕𝑢)−1⏟𝜆⊤𝜕𝑓𝜕𝜃,

(17)

where 𝜆 is referred to as the adjoint variable. Let 𝑛𝑖 be the dimension of the output 𝑢𝑖 of layer 𝑖, so that the stacked state 𝑢 has dimension 𝑑=∑𝑖=1𝑁𝑛𝑖. For simplicity, we assume that the final output 𝑢𝑁 is scalar, i.e. 𝑛𝑁=1. Then 𝑢𝑁=𝑒𝑑⊤𝑢, where 𝑒𝑑 is the last canonical basis vector in ℝ𝑑. In this case we have that

𝜕𝐿𝜕𝑢=2(𝑒𝑑⊤𝑢−𝑦)𝑒𝑑⊤=2(𝑢𝑁−𝑦)𝑒𝑑⊤=𝑔𝑁⊤.

(18)

Now what is left to compute is 𝜕𝑓𝜕𝑢 and 𝜕𝑓𝜕𝜃. Starting with 𝜕𝑓𝜕𝑢 we note that because 𝑓 only propagates the 𝑢𝑖’s forwards the resulting partial derivative is a lower block triangular matrix of the form

𝜕𝑓𝜕𝑢=[𝐼0⋯0−𝜕Φ2𝜕𝑢1𝐼⋯0⋮⋮⋱⋮−𝜕Φ𝑁𝜕𝑢1⋯−𝜕Φ𝑁𝜕𝑢𝑁−1𝐼]=𝐿.

(19)

Now is a good place to stop and think of a key concept of backpropagation: The resulting computational graph must be a Directed Acyclic Graph (DAG). This is indeed equivalent to stating that 𝜕𝑓𝜕𝑢 should be a lower triangular matrix. This is an important property as the adjoint method requires us to invert 𝜕𝑓𝜕𝑢, which can be done cheaply for a lower triangular matrix. Even more important is that the diagonal blocks are the identity, meaning that forward/backward substitutions can be done without any matrix inversions at all.

What is left is to compute 𝜕𝑓𝜕𝜃, which standardly is done as

𝜕𝑓𝜕𝜃=−[𝜕Φ1𝜕𝜃⋮𝜕Φ𝑁𝜕𝜃]⏟𝑀⊤=−𝑀⊤.

(20)

Now, in case of the layers not sharing any parameters the matrix 𝑀⊤ will have a block diagonal structure, i.e.

𝑀⊤=blkdiag(𝜕Φ1𝜕𝜃1,…,𝜕Φ𝑁𝜕𝜃𝑁),𝜃=[𝜃1⋮𝜃𝑁],

(21)

where 𝜃𝑖 are the parameters of layer 𝑖.

Putting everything together we find that the gradient of 𝐿 with respect to 𝜃 is given by

dℒ︀d𝜃=𝜕𝐿𝜕𝜃−𝜕𝐿𝜕𝑢(𝜕𝑓𝜕𝑢)−1𝜕𝑓𝜕𝜃=𝜇𝜕ℛ︀𝜕𝜃−(𝑔𝑁⊤𝐿−1(−𝑀⊤))=𝜇𝜕ℛ︀𝜕𝜃+2(𝑢𝑁−𝑦)𝑒𝑑⊤𝐿−1𝑀⊤.

(22)

As noted previously both 𝐿−1 and 𝑀⊤ are structured, meaning that the above can be computed efficiently.

2.1. How to compute the elements of 𝐿 and 𝑀⊤

For a standard linear layer an activation function 𝜎 is usually applied element wise. In practice this means that we really should look at the rows of Φ𝑖 separately. For the 𝑗th row the gradients are easily seen to be

∇𝑢𝑖−1𝜎(𝑤𝑗⊤𝑢𝑖−1+𝑏𝑗)=𝜎′(𝑤𝑗⊤𝑢𝑖−1+𝑏𝑗)𝑤𝑗,Goes into 𝐿∇𝑤𝑗𝜎(𝑤𝑗⊤𝑢𝑖−1+𝑏𝑗)=𝜎′(𝑤𝑗⊤𝑢𝑖−1+𝑏𝑗)𝑢𝑖−1,Goes into 𝑀⊤∇𝑏𝑗𝜎(𝑤𝑗⊤𝑢𝑖−1+𝑏𝑗)=𝜎′(𝑤𝑗⊤𝑢𝑖−1+𝑏𝑗),Goes into 𝑀⊤

(23)

Using the above we see that

𝜕Φ𝑖𝜕𝑢𝑖−1=diag(𝜎′(𝑊𝑖𝑢𝑖−1+𝑏𝑖))𝑊𝑖,

(24)

where 𝜎′(⋅) is applied element wise. Now for 𝜕Φ𝑖𝜕𝜃𝑖 we have to pick a way of how to vectorize the parameters. Here we choose

𝜃𝑖=[vec(𝑊𝑖)𝑏𝑖],

(25)

where vec(𝑊) vectorizes by stacking the columns of 𝑊. Using the vectorization we can write the sought after sensitivity as

𝜕Φ𝑖𝜕𝜃𝑖=diag(𝜎′(𝑊𝑖𝑢𝑖−1+𝑏𝑖))([𝑢𝑖−1⊤1]⊗𝐼𝑛𝑖).

(26)

While the Kronecker product above does result in a sparse matrix, it is even more structured. Using the standard property of Kronecker products, (𝐴⊗𝐵)𝑣=vec(𝐵mat(𝑣)𝐴⊤), where mat(𝑣) reverses the column-stacking operation vec with dimensions compatible with 𝐴 and 𝐵, its products with vectors can be computed without forming it, e.g. ([𝑢𝑖−1⊤1]⊗𝐼𝑛𝑖)𝜃𝑖=𝑊𝑖𝑢𝑖−1+𝑏𝑖.

A final remark here is that the diagonal matrices that go into the elements of 𝐿 and 𝑀⊤ are the same. That is if we define

𝐷=diag(𝜎′(𝑊1𝑢0+𝑏1),…,𝜎′(𝑊𝑁𝑢𝑁−1+𝑏𝑁))=blkdiag(diag(𝜎′(𝑊1𝑢0+𝑏1)),…,diag(𝜎′(𝑊𝑁𝑢𝑁−1+𝑏𝑁))),

(27)

then it follows that

𝐿=𝐼−𝐷blkdiag(𝑊2,…,𝑊𝑁,−1),𝑀⊤=𝐷blkdiag([𝑢0⊤1]⊗𝐼𝑛1,…,[𝑢𝑁−1⊤1]⊗𝐼𝑛𝑁),

(28)

with the slightly unusual notation that blkdiag(⋅,−1) denotes the lower block diagonal matrix. Here its (𝑖,𝑖−1) block is 𝑊𝑖 for 𝑖=2,…,𝑁, with all other blocks zero and block row and column sizes 𝑛1,…,𝑛𝑁. The weight 𝑊1 acts on the fixed input 𝑢0 and therefore does not appear in 𝐿.

In this example we set 𝜇=0, so the objective contains only the squared error. The implementation uses BlockDiagonalMatrices.jl and Kronecker.jl in order to efficiently represent the involved matrices.

function backsub(derivs, weights, b)
28

30
    @views for (d,Wt) in zip(reverse(derivs), reverse(transpose.(weights)))

33
        dst = stop-n-nprev+1:stop-n
34

function ∇L(θ, layer_sizes, u0; y=0.0)
61
    # First unpack the parameter vector
62
    Ws, bs = unpack_θ(θ, layer_sizes)
63
    # Forward pass includes derivative information
64
    kron_blocks, derivs, uN = forward_pass(u0, zip(Ws, bs))
65
    # S has subdiagonal blocks W_2,...,W_N; L = I - D*S and M^T = D*K
66
    D = Diagonal(vcat(derivs...))
67
    K = BlockDiagonal(kron_blocks)
68
    g = zeros(eltype(θ), sum(layer_sizes[2:end]))
69

70

71
    grad_adjoint = (backsub(derivs[2:end],Ws[2:end],g')*D)*K
72
    return grad_adjoint'
