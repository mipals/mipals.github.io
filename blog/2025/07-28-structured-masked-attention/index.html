Masked Attention (MA) is given by the relation [1]

𝐌=𝐁⊙𝐋,

(1)

where 𝐋 is a mask applied to the matrix 𝐁 using the elementwise Hadamard product (denoted by ⊙). When the mask is structured one can most often apply multiplication with 𝐌 efficiently, and we refer to the masked attention as Structured Masked Attention (SMA). In the simplest case of 𝐋 being a lower triangular matrix filled with ones the SMA reduces to

𝐌=𝐁⊙𝐋=tril(𝐁),

(2)

which can be viewed as a weighted cumulative sum. While the above is a structured computation, it is not efficient unless 𝐁 itself has some structure. An example of when 𝐁 is structured is when it is of low-rank (i.e., 𝐁=𝐔𝐕⊤). The resulting SMA is a semiseparable matrix for which multiplication can be applied in linear time [2].

In general if 𝐋 is a low-rank matrix (of rank 𝑝) then multiplication with 𝐌 scales as 𝑝-times the scaling of multiplication with 𝐁 as

𝐌𝐱=(𝐁⊙𝐔𝐕⊤)𝐱=∑𝑖=1𝑝diag(𝐮𝑖)𝐁diag(𝐯𝑖)𝐱,

(3)

for which we see that we need to perform 𝑝 multiplications with 𝐁 as well as 2𝑝 diagonal multiplications.

1. State-space models as structured matrices

First we recap that a state-space model is given by the equations

𝐡𝑖=𝐀𝑖𝐡𝑖−1+𝐁𝑖𝐱𝑖,𝐲𝑖=𝐂𝑖⊤𝐡𝑖,

(4)

An alternative way to view the state-space model is through the lens of structured matrices. We take 𝐡0=𝐁0𝐱0, corresponding to a zero state before the first input. In particular a state-space model up until time step 𝑇 can also be written using block matrices as well as block bidiagonal matrices as

[𝐈−𝐀1𝐈⋱⋱−𝐀𝑇−1𝐈]⏟𝐀[𝐡0𝐡1⋮𝐡𝑇−1]=[𝐁0𝐱0𝐁1𝐱1⋮𝐁𝑇−1𝐱𝑇−1]=[𝐁0𝐁1⋱𝐁𝑇−1]⏟𝐁[𝐱0𝐱1⋮𝐱𝑇−1]

(5)

We know that by simply iterating forwards in time we can compute the states in linear time. For the following generator representation, assume that each transition matrix 𝐀𝑖, 𝑖=1,…,𝑇−1, is invertible. A structured representation of the inverse of the bidiagonal matrix 𝐀 can be constructed and applied in linear time for fixed state dimension, using

𝐀−1=tril([𝐈𝐀1𝐀2𝐀1⋮𝐀𝑇−1…𝐀1]⏟𝐔[𝐈𝐀1−⊤(𝐀2𝐀1)−⊤⋮(𝐀𝑇−1…𝐀1)−⊤]⊤⏟𝐕⊤),

(6)

This type of matrix structure is called semiseparable [2]. Using this structured representation of 𝐀−1 we can compute the hidden states efficiently as

[𝐡0𝐡1⋮𝐡𝑇−1]=tril([𝐈𝐀1𝐀2𝐀1⋮𝐀𝑇−1…𝐀1][𝐈𝐀1−⊤(𝐀2𝐀1)−⊤⋮(𝐀𝑇−1…𝐀1)−⊤]⊤)⏟𝐀−1[𝐁0𝐁1⋱𝐁𝑇−1][𝐱0𝐱1⋮𝐱𝑇−1],

(7)

Similarly, the output 𝐲 can be computed by applying the output matrices 𝐂𝑖 in a blocked fashion to the hidden states, i.e.

[𝐲0𝐲1⋮𝐲𝑇−1]=[𝐂0⊤𝐂1⊤⋱𝐂𝑇−1⊤]⏞𝐂⊤[𝐈−𝐀1𝐈⋱⋱−𝐀𝑇−1𝐈]−1[𝐁0𝐁1⋱𝐁𝑇−1]⏟𝐌[𝐱0𝐱1⋮𝐱𝑇−1]

(8)

2. State-space models as SMAs

In this section we aim to derive that the simplified SSM in the Mamba-2 paper is a special case of Structured Masked Attention (SMA) [1], i.e., that the multiplication

𝐌𝐱=[𝐂0𝐂1⋱𝐂𝑇−1]⊤(𝐀−1([𝐁0𝐁1⋱𝐁𝑇−1]𝐱)),

(9)

can be written differently as

𝐌𝐱=(𝐁⊙𝐋)𝐱,

(10)

The SSM in the Mamba-2 paper restricts the dynamics of 𝐀 to be scalar-times-identity dynamics in order for the mask to be structured [1]. In short this restriction means that the dynamics for all hidden states are independent but equal.

𝐡𝑡=(𝑎𝑡𝐈)𝐡𝑡−1+𝐛𝑡𝑥𝑡,𝐲𝑡=𝐜𝑡⊤𝐡𝑡.

(11)

From a practical point-of-view this means that we can collect each index of the dynamics and treat them separately. The resulting 𝐀-matrix can be described by a Kronecker product (depending on how we organize the states it’s either 𝐀=𝐚⊗𝐈𝑛 or 𝐀=𝐈𝑛⊗𝐚). In the following we choose to separate the states, resulting in 𝐀 having the form

𝐀=𝐈𝑛⊗𝐚,𝐚=[1−𝑎11⋱⋱−𝑎𝑇−11],

(12)

For the following scalar generator representation, assume that 𝑎𝑖≠0 for 𝑖=1,…,𝑇−1. Using that the inverse of a Kronecker product is the Kronecker product of the inverses it follows that

𝐀−1=𝐈𝑛⊗𝐚−1,𝐚−1=tril([1𝑎1⋮𝑎𝑇−1…𝑎1]⏟𝐮[1𝑎1−1⋮(𝑎𝑇−1…𝑎1)−1]⊤⏟𝐯⊤),

(13)

where we further used that the inverse of a bidiagonal matrix is semiseparable. Furthermore, we have to re-arrange 𝐁 and 𝐂 which results in

𝐁=[diag(𝐛(1))⋮diag(𝐛(𝑛))],𝐛(𝑘)=[𝑏0(𝑘)⋮𝑏𝑇−1(𝑘)],𝐂=[diag(𝐜(1))⋮diag(𝐜(𝑛))],𝐜(𝑘)=[𝑐0(𝑘)⋮𝑐𝑇−1(𝑘)],

(14)

where 𝑏𝑡(𝑘) and 𝑐𝑡(𝑘) denote the 𝑘th entries of 𝐛𝑡 and 𝐜𝑡. The final multiplication will therefore look as

𝐂⊤𝐀−1𝐁⏟𝐌𝐱=(∑𝑘=1𝑛diag(𝐜(𝑘))𝐚−1diag(𝐛(𝑘)))𝐱=(∑𝑘=1𝑛(𝐜(𝑘)𝐛(𝑘)⊤)⊙𝐚−1)𝐱.

(15)

Finally, using the properties of the Hadamard product we get to the Structured Masked Attention form that we were looking for

(𝐂⊤𝐀−1𝐁)𝐱=(∑𝑘=1𝑛(𝐜(𝑘)𝐛(𝑘)⊤)⊙𝐚−1)𝐱=(([𝐜(1)…𝐜(𝑛)][𝐛(1)⊤⋮𝐛(𝑛)⊤])⊙𝐚−1)𝐱.

(16)

This means that the SSM dynamics can be interpreted as a structured masked attention mechanism. Note that in the case of the dynamics being independent but different (i.e., we would have 𝐚(𝑘) rather than just 𝐚) the SSM dynamics would result in a sum of masked attentions, i.e.,

(𝐂⊤𝐀−1𝐁)𝐱=(∑𝑘=1𝑛(𝐜(𝑘)𝐛(𝑘)⊤)⊙(𝐚(𝑘))−1)𝐱

(17)

Random.seed!(42)

T = 10          # Sequence length

11
a_blks = rand(T-1)
12
a = Bidiagonal(ones(T), -a_blks, :L)
13
A = kron(I(n),a)        # Kronecker product with identity
14
15
# The blocks are now size equal to the sequence and a block for each state!
16
B_blks = [rand(T) for _ in 1:n]
17
C_blks = [rand(T) for _ in 1:n]  
18
# Collecting the blocks into the B and C
19
B = vcat(Diagonal.(B_blks)...)
20
C = vcat(Diagonal.(C_blks)...) 
21
22
# We want to see if the full matrix M = C'*(A\B) can be written as
23
# structured masked attention, i.e.,
24
# M = (CB')\circ a^{-1}. For this we start by computing a^{-1}
25
ai = inv(a) # We ignore here that inv(a) is semiseparable
26
@test C'*(A\B) ≈ sum(i-> Diagonal(C_blks[i])*ai*Diagonal(B_blks[i]), 1:n)
27
@test C'*(A\B) ≈ sum(i->(C_blks[i]*B_blks[i]') .* ai, 1:n)
28
29
# We can collect the terms and write it as Structured Masked Attention!
30
Cn = hcat(C_blks...)
31
Bn = hcat(B_blks...)
32
@test C'*(A\B) ≈ (Cn*Bn') .* ai

34
# We can apply the semiseparable structure of the inverse when multiplying!
35
ai_blks = [prod(a_blks[1:i-1],init=1.0) for i in 1:T]

v = vcat(inv.(ai_blks)...)

41
x = randn(T)
42
