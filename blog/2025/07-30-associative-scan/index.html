Associative Scan

30 July 2025 · Download PDF

Contents
  1. Bibliography

Recently a plethora of methods within machine learning have made use of state-space models (SSMs) to model sequences [1], [2], [3], [4]. While the early S4 model is computed as a convolution [1], a big reason for the success of later models such as S5 [2] and Mamba [3] is their usage of the associative scan operation to parallelize the state computation on the GPU. In my opinion this is a neat trick that was poorly explained in the original papers (although Appendix B in [4] does explain it for the scalar case), and I will therefore explain it in more detail in this blog post. The aim is to show that composing the transitions of a (linear) state-space model

𝐡𝑖=𝐀𝑖𝐡𝑖−1+𝐁𝑖𝐱𝑖,𝐲𝑖=𝐂𝑖𝐡𝑖,

(1)

is associative11 Associativity simply means that repeated applications of the operator (denoted by •) can be grouped arbitrarily, i.e., that 𝑎•(𝑏•𝑐)=(𝑎•𝑏)•𝑐. The order of the operands must still be kept, as the operator need not be commutative. Examples of associative operators are addition and multiplication, including matrix multiplication.. In short this means that the states of a (linear) state-space model up until time step 𝑇 can be computed in parallel using an associative scan operation. For details on the associative operation open the example box below.

While the above computation is trivial and easily computed by looping from the first to last element in the vector, the main idea of the associative scan is that the operator can be applied pairwise in parallel. That means if enough processors are available the computation can be done in 𝒪︀(log𝑇) time rather than the trivial implementation of 𝒪︀(𝑇).

The first step in showing the associativity of the state-space model is to define the transition of the state-space models using matrix multiplication (which is associative) by embedding the transition into a larger matrix 𝐬𝑘 as follows

𝐬𝑘=[𝐀𝑘𝐁𝑘𝐱𝑘𝟎1],𝐬0=[𝟎𝐡0𝟎1]

(2)

Using the definition of 𝐬𝑘 the state transition from state 𝑘−1 to state 𝑘 can be computed using matrix multiplication as

𝐬𝑘𝐬𝑘−1=[𝐀𝑘𝐀𝑘−1𝐀𝑘(𝐁𝑘−1𝐱𝑘−1)+𝐁𝑘𝐱𝑘𝟎1].

(3)

Using this we can compute the 𝑖th state of the state-space model as

𝐡𝑖=[𝐈𝟎](∏𝑘=𝑖0𝐬𝑘)[𝟎1].

(4)

Given that the cumulative product can be computed using the associative scan operator the full dynamics can be computed as

𝐩𝑖=associative_scan(𝐬𝑖,init=𝐬0)𝐲𝑖=𝐂𝑖𝐡𝑖=[𝐂𝑖𝟎]𝐩𝑖[𝟎1].

(5)

While the above works, it can be simplified slightly. As we are really only interested in the top row of blocks (the accumulated product 𝐩𝑖 has 𝐡𝑖 in its top-right block), we can instead define elements by just the top row, i.e., 𝐬𝑘=[𝐀𝑘𝐁𝑘𝐱𝑘], and then define the operator (denoted by •) by how the top row propagates. For general pairs this reads

[𝐀″𝐛″]•[𝐀′𝐛′]=[𝐀″𝐀′𝐀″𝐛′+𝐛″],

(6)

which is the top block row of the product [𝐀″𝐛″𝟎1][𝐀′𝐛′𝟎1]. The operator is therefore associative, because matrix multiplication is. The SSM states can then be computed as 𝐩𝑖=𝐬𝑖•𝐩𝑖−1 with 𝐩0=𝐬0=[𝟎𝐡0], and 𝐡𝑖 is the right block of 𝐩𝑖.

As a final remark note that while the associative scan is parallelizable it performs matrix-matrix products of the form 𝐀𝑘𝐀𝑘−1 which will be computationally prohibitive unless 𝐀𝑘 has structure (e.g., diagonal or low-rank). This is one of the reasons why e.g. Mamba-2 utilizes a scaled identity as its 𝐀𝑘 [4].
